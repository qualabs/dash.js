Callback events example

This example illustrates how DASH Callback Events signal a DASH client to issue an HTTP GET request to a specified URL while ignoring the response.

The URL is included in a video segment, and segments are verified because the MPD contains an InbandEventStream tag with schemeIdUri urn:mpeg:dash:event:callback:2015 and value 1.
